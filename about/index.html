About the application

Canvas Studio

A local 3D CAD workspace for designing parts and preparing models for 3D printing.

Created by
Damian Borkowski
Version
2.0.0
Available for
Desktop and browser
Application license
Proprietary

Model and refine

Build solids from shapes and sketches. Cut openings, round or bevel edges, create shells, and add surface text, paint or relief.

Work from technical drawings

Read dimensions from an image or PDF with local OCR. Review the detected values before applying them to the model.

Save and export

Keep an editable project in Canvas Studio’s 3DCS format.

Export STEP for CAD work, STL or 3MF for printing, or OBJ for mesh workflows. Available formats depend on the geometry.

Manual modeling runs locally and works without an AI account. The AI Agent is optional.
